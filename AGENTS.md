# Project guidance

- Keep UNHEARD free and browser-based. Do not add paid APIs, an OpenAI API key, authentication, a backend, or a database.
- Use synthesized Web Audio sounds; do not introduce recordings with unclear licensing or paid assets/fonts/services.
- Preserve the workshop-friendly separation of preset data, synthesis, gesture mapping, canvas rendering, React interface, scales, and CSS.
- Keep runtime dependencies minimal. Use React, Vite, JavaScript, React Router, Pointer Events, and Canvas without large UI or animation frameworks.
- Run `npm test` and `npm run build` after code changes. Check actual browser interactions for changes to input/audio.
- Maintain semantic HTML, visible keyboard focus, native control labels, usable touch targets, reduced motion, responsive layouts, and friendly error/empty states.
- Keep the contemporary Indian visual direction restrained: indigo and ivory foundation, deliberate instrument-specific accents, geometric sound motifs, no inaccurate partner logos.
- Synthesized presets are inspired by instruments; never claim authentic acoustic emulation. The Indian-inspired pentatonic arrangement is not a complete/authentic raga system.
- Only create/resume AudioContext after explicit user activation. Keep conservative gain, nonzero envelopes, finite source lifetimes, timer cancellation, and node cleanup.
- Avoid adding scope that obscures the workshop's learning goals. Document larger features under Next Build.
